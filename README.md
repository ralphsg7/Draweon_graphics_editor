# Draweon_graphics_editor

This software was developed as part of the **Software Engineering Lab (Course Code - CS3074)** during the 6th semester at the **National Institute of Technology, Rourkela**, under the supervision of **Professor Dr. S. Asha**.

The project is a graphics editor tool designed for creating line-based drawings with various graphical entities. It provides a set of features to help users create, modify, and manipulate graphical objects efficiently.

## Overview

For users who are new to graphics editing software, we recommend exploring basic drawing tools in programs like MS Word, PowerPoint, or other professional design tools like AutoCAD. Familiarizing yourself with these common features will give you a better understanding of what this graphics editor offers.

## Key Features

The graphics editor includes the following major functionalities:

- **Creation of Geometric Shapes:** Users can create various geometric entities such as circles, ellipses, rectangles, lines, polygons, and text elements.
- **Object Manipulation:** Users can copy, move, or delete selected objects as needed.
- **File Management:** Users can save their creations under custom filenames and load previously saved drawings from the disk.
- **Bitmap Importing:** Bitmap images can be imported into specific locations within the drawing.
- **Screen Controls:** Users can define a rectangular screen area and zoom in to fit the drawing to the screen. Additional options for fitting the entire design to the screen and panning in any direction are also available.
- **Grouping of Objects:** Users can create object groups, which makes managing and editing complex drawings easier. Groups can be moved, copied, or deleted as a single unit.
- **Clipboard Support:** The editor provides 10 clipboards, allowing users to copy selected objects (including groups) for later pasting at different locations.
- **AI Assistance:** The editor also includes a smart AI assistant that helps guide users in creating use case diagrams, class diagrams, and other software engineering-related concepts. This feature is designed to improve the user experience and provide extra support during learning.

## How to Use

To begin using the graphics editor, follow these steps:

1. Install Visual Studio on your computer.
2. Open the project in Visual Studio.
3. Click on the "Start" button to run the application.
